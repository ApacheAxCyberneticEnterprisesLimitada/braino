# Braino v0.1 conformance

The v0.1 release gate is executable:

```sh
pnpm conformance
```

It must finish in less than ten minutes on a clean Docker host. The command
runs deterministic tests against real PostgreSQL semantics through PGlite,
then exports the committed source into a disposable directory, builds the
application and CodeLinker images, boots a fresh stack with no model-provider credentials, performs
first-run setup and an authenticated authoring/search round trip, and completes
a destructive PostgreSQL backup/restore drill. The temporary containers,
volumes, image, credentials, and source export are removed on exit.

## Required proofs

| Contract | Executable proof |
| --- | --- |
| First boot creates exactly one workspace and refuses a second | `single-workspace.real-db.test.ts` plus the clean Docker setup |
| The owner can administer the workspace and deployment while other roles cannot | `workspace-admin.real-db.test.ts`, `admin-console.test.ts`, plus the live `/admin` request |
| Owners manage team roles and per-type write grants without self-lockout | `collaborators.real-db.test.ts` |
| Authoring is atomic, policy-checked, relational, lifecycle-aware, and immutable | `changesets.real-db.test.ts` plus the live changeset request |
| Search is deterministic and works before embeddings or indexing | `workspace-search.real-db.test.ts` plus the live search request |
| MCP tokens, briefs, search, feedback, and changesets work without a model | `mcp-core.real-db.test.ts` |
| Generic webhook retries are idempotent and revocation is immediate | `incoming-webhooks.real-db.test.ts` |
| GitHub tokens are encrypted and code/issue/PR sync is idempotent and audited | `github-connections.real-db.test.ts` |
| Docker topology, CodeLinker health, required secrets, versioned migrations, backup, restore, upgrade contract, and signed multi-arch releases are present | `schema-apply-once.test.ts`, `self-hosted-compose.test.ts`, and the live backup/restore drill |
| New UI stays inside Braino's existing design language | `design-language.test.ts` |

PostgreSQL is the only source of truth. The restore proof deliberately deletes
the authored conformance record, restores the backup, clears the rebuildable
Qdrant projection, and verifies that the record is present again.

## Release enforcement

`.github/workflows/release.yml` runs `pnpm verify` and then `pnpm conformance`
before building, publishing, and signing either version-tag image. A failure or a
runtime longer than 600 seconds blocks publication.
